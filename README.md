# 浊仙 · 修仙暗黑放置刷宝

> 一款**纯前端、单机、挂机**的修仙题材刷宝游戏。打开网页就玩，不用注册、不用联网、没有内购。

**直接玩：<https://kabshou.github.io/zhuoxian/>**

三千年前，大能渡劫失败，劈开了九幽魔渊；浊气自此上涌，人间灵气尽浊。
你灵根已废，却唯独能把浊气炼成修为 —— 此谓「浊脉」。**越强，越脏。**

---

## 这是什么游戏

玩法骨架是「暗黑破坏神 / 流放之路」的刷宝循环，节奏是挂机放置：

- **战斗全自动，决策全留给你** —— 你不用操作战斗，但要决定：去哪层刷、换哪件装备、点哪条天赋线、什么时候轮回。
- **76 层魔渊**，越深越脏：怪物更肥也更疼，灵纹品阶更高，但浊气也在涨。
- **九境八十一重**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。
- **一次通关约 24 小时**（满级约 4.2 小时 + 装备成型 + 收集），之后进入周目（轮回）继续加深。

## 怎么玩（三分钟上手）

1. 选一个**道统**（六选一，之后不能转职）。
2. 什么都不用按，战斗自己打。**浊气**会随战斗上升：伤害变高、回气变慢，满了会「浊化爆发」然后虚弱 —— 这是本作的核心张力，不是惩罚。
3. 捡到更好的**法宝**会自动换上；想自己挑就按 `B` 开背包。
4. 想换层刷按 `P` 开**秘境图**（格子上越亮 = 修为越多）。
5. 打镇守、往下潜、攒渊痕、满级后按 `N` **入轮回**。

## 几个设计选择

- **没有转生/开箱/内购**。唯一的「重来」是满级后的轮回，它保留渊痕、图鉴、成就。
- **数字都可查**：伤害有拆解面板（`D`）、产出有秘境图热度、进度有统计面板（`Y`）。
- **没有服务器**：进度只存在你这台浏览器的 `localStorage` 里。换设备 / 清缓存前请用 `S` → 导出。
- **自动存档 30 秒一次**，并且**双写备份**：主档坏了会自动回退到上一次备份并提示你导出。

## 技术

- TypeScript + Vite + Canvas 2D，**零运行时依赖**，纯静态产物（约 180 KB / gzip 62 KB）。
- 无后端、无埋点、无网络请求。
- 存档是纯 JSON（`zhuoxian.save.v1`），可以手工改，也可以导出备份。

```bash
npm ci
npm run dev      # 本地开发（127.0.0.1:5274）
npm test         # 单测
node tools/gate.mjs   # 发布前五道门：类型 / 单测 / 死接线审计 / 构建 / 产物自检
```

## 项目是怎么长出来的

这是一个**从零学做游戏**的项目：作者白天上班、每天两小时，用 AI 结对推进：

1. 先写需求文档（要什么、明确不做什么、怎么算做完）；
2. 再写数值文档（所有曲线先算清楚，再写代码）；
3. 每个系统落地时同时写**探针**（真浏览器里点一遍）—— 现在共 35 个探针、537 项断言；
4. 所有「为什么这么定」写进决策簿，而不是留在聊天记录里。

**为什么值得看**：这个仓库里记录的不只是代码，还有一串真实踩过的坑——
比如「单测全绿但功能没接上线」（浊气觉醒整整四个月没生效）、
「测试测的是没人用的那个函数」（四份重复的几何公式）、
「注释写了用途但字段从来没被写过」（`floorMinutes`）。这些坑都写进了决策簿和门禁里。
