## 2. 逐条对照（只列这次有变化或仍有问题的）

### 2-1 护甲减伤 ✅（GDD 缺 cap）

`k=50+10×level`、`r=armor/(armor+k)`、`min(0.9, …)`。护体 0/100/200/400/540/1000 @lv1 → 0/62.50/76.92/86.96/**90.00（封顶）**/90.00；GDD 公式无 cap 时 540 应 91.53%、1000 应 94.34%。敌人等级越高同一护体越弱（lv50 · 护体 1000 → 64.52%），符合「越深越难」。

### 2-2 浊气 ✅ + 状态机（GDD 无数字）

伤害 `1/1.125/1.25/1.375/1.5`、回复 `1/0.9/0.8/0.7/0.6`（浊气 0~100），与 GDD 5.2 逐位一致。状态机为代码单方面约定：满值 → `corrupting` 5s（伤害 ×2，叠沸腾 ×3）→ `weak` 4s、`value=0`（伤害 ×0.6、受伤 ×1.3、治疗再 ×0.5 → 实测 0.30）；平静期衰减 1.5/s（50 → 48.50/秒）。

### 2-3 伤害管线 ⚠️（形式不同、结果可对齐）

`base → flat → increased(×) → more(×) → externalMore(×，浊气) → roll 0.9~1.1 → 暴击 → 抗性/护甲 → max(1,round)`。实测 `base100` vs 护体100/lv1 → `37.5/38`；暴击 → 150；暴击+护甲 → `56.25/56`。GDD 的 `(1+境界加成)` 代码里没有独立乘区（境界只抬属性），见 §3-5。

### 2-4 暴击倍率 ✅（GDD 陈旧）

`critMultiplier([]) = 1.5`，`flat+0.2 → 1.7`；`stats.ts:107` 基础 1.5。DECISIONS L38 已判 GDD 的 1.0 陈旧。
